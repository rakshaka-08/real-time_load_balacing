# Module 33: Algorithm benchmark analytics

Module 33 adds a controlled benchmark workspace to the Analytics page. It submits the same selected tasks, virtual machines, seed, and redistribution setting to GA, HBA, Hybrid GA + HBA, LPT, and SPT.

The interface displays actual backend benchmark results as metric bar charts and a detailed comparison table. It covers system utilization, response time, makespan, load imbalance, scheduler execution time, and redistribution count.

The results apply only to the selected workload and configuration; the interface does not claim that one algorithm is universally superior.
